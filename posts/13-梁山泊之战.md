S13 梁山泊之战

本关中途可以召唤3个1级店货装的猴毛，但同时会引出呼延灼（9级减策甲）、扈三娘（9级紫绶）和十几个连环马（9级黄金甲），根本没法打。只能不召猴毛，我军自己手打开场就在场的敌军：

- <=2级的敌军优先用群法收，我军恰有两个会群法的文官，徐茂公有九宫范围的火龙、水龙，扁鹊有没羽箭范围的大毒烟。
- \>=3级的敌军优先用丈八和飞燕的穿透收。

本关需2个石雷、3个土雷，不足备齐。

开场：

- 主角：豆甲。
- 岳飞：鬼神枪、炎帝甲。
- 穆桂英：方天、经验书。
- 赵飞燕：双股剑。
- 高长恭：破甲刀（给飞燕带的）、1级硬皮甲。
- 徐茂公：5级鹤羽扇、1级兽皮衣、美人图。
- 扁鹊：5级鹤羽扇、7级无缝、+2马。
- 鲁大师：丈八、黄金甲、乾坤圈，穿刺套装。
- 武松：金箍棒、经验书。

我军每回合有5个人（主角、徐茂公、扁鹊、鲁大师、飞燕）要吃公孙胜的大招（HP-100），因此有5个行动人次定死了是要吃豆子的，能做其他操作的也只有5个行动人次，会很紧张，主角带豆甲在被攻击掉血时可以省出一个行动人次。

城外，秦明、董平都是没羽箭攻击，不难应付。16个武斗兵是四向攻击，最上面一排武斗兵里有一个3级的，所以这排武斗兵要用丈八收，主角、岳飞、穆桂英、高长恭、鲁大师5选1：

- 主角后面剧情单挑多，必然不考虑。
- 岳飞后面要连续挑卢俊义、吕布，这里如果出手挑完吕布必升级。
- 穆桂英的经验要留给坂泉，也是要靠我军手打的。
- 高长恭为了刷特技，每关能出尽出，过早得经验升级的话，会拉高敌军等级，导致我军有单挑的武将多得经验。
- 鲁大师是最适合的，全程无剧情单挑。

鲁大师收掉3个武斗兵后面临一个问题，敌军阶段如何不挨打不出反击？让一个武将不被打大致有3种方法：

1. 埋地雷，敌军武将到这儿打他直接被封行动，没法攻击。
2. 提高防御、增加血量、降低嘲讽，让敌军不来打他。
3. 让某个敌军到这儿，但攻击的是其他我军，这样其他敌军就失去这个攻击位置了。

鲁大师右边是山地，方法1行不通；方法2也不行，敌军武斗兵攻击力实在太低了，对我军武将仇恨值普遍都是5，实际打谁很难判断；稳妥点只能用方法3，八戒到鲁大师左边落位（顺便给扁鹊吃智力果），这样董平会到鲁大师右边打八戒，武斗兵就没法占这个位置了。

高长恭前出埋石雷，高长恭穿的1级硬皮甲，除八戒外最嘲讽，先动的4号武斗兵会来打他，踩石雷炸残自己，穿透5号武斗兵，同时帮高长恭出特技，正所谓一“石”三鸟。

敌军阶段，吴用放大招，我军定身、中毒，精神力下降。

内城8个梁山头领，卢俊义会被岳飞挑掉，琼英1级，剩下6个都是高等级，且除林冲穿了6级减策甲外，其他都是9级宝物防具，硬得要命，只能靠飞燕打了。

这6个武将可以分成3组穿透：鲁智深、林冲；宋江、吴用；关胜、公孙胜，攻击顺序如下

- 先打鲁智深、林冲，因为鲁智深会大补给，打别的组鲁智深会帮加血。
- 再打宋江、吴用，吴用大招很烦，而且飞燕不用进内城、不会触发内城敌军主动出击。
- 最后打关胜、公孙胜，打这组飞燕得进内城，敌军开始主动出击，因此需1回合解决，不然关胜9级青龙刀，我军受了公孙胜大招的武将扛不住，而且关胜移动后，也很难保证能再穿透到公孙胜。

第6回合，飞燕双击鲁智深、穿透林冲，打掉他们60%HP，还剩40%。鲁智深、林冲在兵营，敌军阶段会恢复20%，到60%左右（小数取整问题，实际可能会比60%高几点血），不致引起鲁智深加血。

高长恭把8级破甲刀换给飞燕，穆桂英把乾坤圈换给飞燕，这样就是破甲72%了，不用担心比60%高几点血的问题。

本关：

- 扁鹊：4个大毒烟收4拨全1级人头得32\*4=128点经验，1.0 => 1.128。
- 徐茂公：3个火龙/水龙，2次助攻得10\*2=20点经验，1次收全1级人头得32点经验，1.0 => 1.52。
- 鲁班：丈八收3级武斗兵得38+2\*2=42点经验，2次丈八收6级城门得(38+2\*5)\*2=96点经验，1.0 => 1.138。
- 赵飞燕：2次普攻6级城门得(6+2\*5)\*2=32点经验，2次普攻收7级鲁智深、5级林冲得6+2\*6+38+2\*6=68点经验，2次普攻收5级宋江、7级吴用得6+2\*6+38+2\*6=68点经验，升到2.18；2次普攻收5级关胜、12级公孙胜得6+2\*10+38+2\*10=84点经验，2次普攻1级琼英和1级董平得4\*2=8点经验，1.0 => 2.18 => 2.110。
- 岳飞：手动单挑5级卢俊义得38+2\*4=46点经验，回归2级飞燕得14点经验，1.32 => 1.92。
- 丈八蛇矛：8.141 => 9.max，鲁班带5回合，3次双击穿透3个敌军。
- 鬼神枪：8.187 => 9.max，岳飞手动单挑卢俊义，出双击。
- 方天：1.145 => 3.20，20回合经验书，鲁班带15回合。
- 金箍棒：7.124 => 8.44，12回合经验书。
- 破甲刀：8.83 => 8.193，6回合经验书，5次普攻穿透得12+12+10+8+8=50点经验。
- 双股剑：1.6 => 1.86，2回合经验书，5次普攻穿透得3\*5\*2\*2=60点经验。

11级公孙胜普攻1级我军得4点经验，由于全屏同仇，出手次数极多，第5回合结束就已经达到11.108。即便第6回合我军用智力果恢复徐茂公、扁鹊的精神力，收掉6个刺客，之后公孙胜依然每回合会出手3次（主动攻击1次，最后一个刺客、董平引起同仇2次），得12点经验，撑不到11回合就升级了，所以没必要急着收那6个刺客。
